DOMINIO v5 — base funcional
1. Sube estos archivos al repositorio de GitHub Pages.
2. No hay Service Worker para evitar cachés durante desarrollo.
3. Los datos se guardan en localStorage del navegador.

5. En Cuentas puedes decidir por separado qué entra en disponible, saldo global y patrimonio.
6. Efectivo y tarjetas se crean como control y quedan fuera de patrimonio por defecto.
